# Archiving XPS-master on Zenodo

Repository: [AliAfruz/XPS-Master](https://github.com/AliAfruz/XPS-Master).
Software author: **Ali Afruz**, **a.a.afruz@gmail.com**, **https://chemitro.ir**.
The prepared software version is **0.2.0** under the **MIT license**.

`CITATION.cff` includes the software title, author, version, description,
keywords, license, and repository URL. No DOI or ORCID has been invented.
Zenodo supports citation metadata from this file; a separate `.zenodo.json`
is unnecessary for this release's metadata.
See [Zenodo's software metadata guide](https://help.zenodo.org/docs/github/describe-software/zenodo-json/).

## Recommended GitHub integration

1. Sign in to Zenodo and link your GitHub account.
2. Enable **AliAfruz/XPS-Master** in Zenodo's GitHub repository list.
3. Check the intended release commit, version, license, author, and local tests.
4. Create a GitHub release from that commit with tag **v0.2.0** and title
   **XPS-master 0.2.0**. Use the matching changelog entry as release notes.
5. Check the imported Zenodo record, including its archived source and author
   metadata, then retain the assigned version DOI and concept DOI.
6. Add the actual DOI to the README and citation metadata after Zenodo assigns
   it. Preserve the archived release tag; document changes in later commits.

Enable the integration before the release that should be archived.
See [enable a repository](https://help.zenodo.org/docs/github/enable-repository/)
and [archive software](https://help.zenodo.org/docs/github/archive-software/).

## Manual deposit

You can instead deposit the clean **XPS-master-v0.2.0-GitHub.zip** source archive.
Choose software as the resource type, enter Ali Afruz as the creator, set the
version to 0.2.0 and license to MIT, and link the GitHub repository. Review
the record and files before publishing. This workflow does not require GitHub
integration.

Keep virtual environments, caches, experimental datasets, and analysis sessions
out of the source deposit unless you deliberately prepare a separate dataset
with appropriate provenance and permissions.
